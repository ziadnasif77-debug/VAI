## 5. Gap analysis (researched alternatives vs. the implementation)
- **Loudness:** the implementation uses a single dynamic pass. FFmpeg's documented accurate path is two-pass linear, and gameplay LRA usually exceeds the configured 11 LU, which forces the dynamic fallback even in two-pass. The consequence is quieter videos than YouTube's −14 reference and compressed dynamics. *Needs owner authorisation (it changes the sound).*
- **NVENC:** p5/hq/VBR with lookahead, but no AQ. FFmpeg exposes `spatial-aq` / `temporal-aq` / `b_ref_mode`, all off by default. The likely gain is in dark, low-motion scenes. Unmeasured: no GPU here.
- **OCR:** EasyOCR 1.7.2 has had no release in 25 months. RapidOCR (ONNX, Apache-2.0) is maintained and needs no torch. Proposal only.
- **Scene detection:** pinned 0.7.1; 0.7.2 changes the Histogram and Hash defaults.
- **ASR:** faster-whisper 1.2.1 is current. Remotion's crash guidance (lower concurrency, retry externally) matches what the project already does.
