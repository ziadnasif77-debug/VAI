## 6. Gap analysis
- **Audio mastering.** The chain is loudnorm (single pass) → alimiter → fades.
  FFmpeg's own docs describe two-pass linear normalisation for files. The gap
  is real but narrow: for bursty gameplay audio, loudnorm itself refuses linear
  mode. So the practical options are (a) accept under-target loudness and keep
  the dynamics, or (b) add controlled compression before loudnorm. That is an
  editorial call for the owner (M-5).
- **Graceful degradation (§95).** The software proxy fallback existed but
  could not have worked with the shipped config (M-4). No test had exercised
  fallback plus the shipped config together; the new unit test covers it.
  Scene detection hard-fails without PySceneDetect (M-8). Whether that is
  intended still needs checking.
- **Portability.** The shipped config was Windows-only at the validator
  level. The build machine documented in PLAN §7 is Ubuntu, so the suite had
  silently stopped running there since `daily.yaml`/`media_source_roots` were
  added.
