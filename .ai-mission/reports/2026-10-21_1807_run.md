### WI-2 Shipped config fails validation off Windows {#wi-2}
- **Problem:** `application.media_source_roots`, `daily.output_directory`,
  `daily.archive_directory` ship as `D:/Gaming 2026/...`. The validators used
  `Path(...).is_absolute()`, which is False for a drive path on POSIX, so
  `load_config()` raised `CONFIG_INVALID` and every test module that loads
  config at import failed to collect (`test_critic.py`, `test_director.py`, …).
  Also: the C-drive guard used `Path.drive`, empty off Windows, so it never
  fired there; and the archive error said `daily.output_directory`.
- **Change:** `backend/config/schema.py` — `_is_absolute()` accepts
  host-absolute **or** Windows drive+root paths; the daily validator names its
  own key (`ValidationInfo.field_name`) and reads the drive with
  `PureWindowsPath` so the C: refusal holds on every host.
- **Tests:** `tests/unit/test_config_portability.py` (10 tests). Without the
  change 6 fail, with it 10 pass (`git stash` check).
- Status: **Verified and implemented.**

### WI-3 `numpy` undeclared as a core dependency {#wi-3}
