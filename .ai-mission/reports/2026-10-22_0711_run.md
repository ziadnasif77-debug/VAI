## 6. Gap analysis

- **Loudness (P1-AUDIO-2).** FFmpeg documents two-pass linear loudnorm for
  files; the project uses single-pass, which is dynamic mode. Measured on a
  60 s synthetic programme (14 s quiet / 6 s loud, repeated): input I -19.2
  LUFS, LRA 7.9 LU → single-pass I -13.7, **LRA 18.0** → two-pass linear I
  -13.7, **LRA 8.0**. The 36 s integration render measures **-13.0 LUFS** for a
  -14 target. Consequence: quiet stretches pumped, loud payoffs flattened
  relative to them, and the platform target missed by up to 1 LU on short
  videos. The mix is embedded in the final composite graph
  (`composite.py:223`), so the fix needs a measurement pass before it.
- **NVENC (P1-NVENC-1).** Final encode uses p5/hq/VBR/lookahead 20 with no AQ
  or multipass. For high-motion gameplay at a fixed bitrate, AQ is the usual
  lever; unmeasured here (no GPU) → hypothesis only.
- **Portability.** The codebase was only ever run on Windows; three
  path/dependency defects (P0-PORT-1/2, P0-DEPS-1) surfaced the moment it ran
  elsewhere. One more remains (`test_rooted.py`, the `D:/Models` shared model
  root) and is environment-specific.
